How Vortex Works

1. Deposit

Users deposit USDC (Base Sepolia or ARC USDC) into the vault. They receive shares representing their position.

2. Autonomous Oracle

The Scheduler automatically triggers the oracle. It fetches live yields via HTTP precompile and runs an ONNX model to calculate optimal weights.

3. Rebalance Suggested

The oracle emits a RebalanceSuggested event with new target weights. Everything happens fully on-chain.

4. Optimized Yield

A rebalancer uses the suggested weights to move funds across protocols, maximizing yield for all depositors.
