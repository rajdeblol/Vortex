How Vortex Works

1. Scheduler Tick

The Ritual Scheduler (0x56e7...) automatically calls tick() at configurable intervals with no keepers required.

2. Live Yield Data

HTTP precompile (0x0801) fetches real-time APY + volatility from public yield APIs (DefiLlama style).

3. ONNX Inference

ONNX precompile (0x0800) runs a regression model that outputs optimal allocation weights in basis points.
